title: "Week 12: Developing the Neural Baseline"
---

This week I implemented the neural semantic baseline.

I used the pretrained **`all-MiniLM-L6-v2` Sentence Transformer model**. Rather than fine-tuning the model as a supervised classifier, I used it as a general-purpose sentence encoder.

I created a short natural-language description for each of the six malware capability categories. Both the report context and these capability descriptions were transformed into sentence embeddings.

For each event, I calculated cosine similarity between its contextual embedding and each capability embedding. The category with the highest similarity score became the neural prediction.

This resulted in a **zero-shot semantic classifier**, meaning the malware capability labels were not used to train the neural model.

This design also provided a useful baseline for testing the central question of the project: whether explicit symbolic information could improve predictions made using general semantic similarity.
