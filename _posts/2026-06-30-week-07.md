This week was spent examining the structure of MalwareTextDB in more detail.

The dataset contains 39 annotated APT reports and uses BRAT annotation files alongside the original text. Understanding how the annotation format worked took some time because information about a malware event could be distributed across several annotation entries.

For example, an Action might be connected to a Subject, Object, or Modifier through explicit relations. That Action could then have additional labels representing a malware capability, tactical objective, or strategic objective.

I decided to treat each annotated **Action** as an individual event for the experiment.

This event-centered representation gave me a way to reconstruct the behavior described in the original report while retaining its structured annotations. My next task was building a preprocessing pipeline that could perform this conversion automatically.
