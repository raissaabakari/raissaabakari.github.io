This week I began implementing the dataset preprocessing pipeline in Python.

The parser extracts each annotated Action and connects it with its associated subject, object, modifiers, capability, tactical objective, strategic objective, and action-name annotations. It also retains the surrounding natural-language context.

The resulting representation gives each event two parallel forms of information:

- natural-language context for neural semantic analysis;
- structured action and entity information for symbolic analysis.

The full conversion produced **2,975 action-level events from all 39 MalwareTextDB reports**. Of these, 2,524 had an associated malware-capability annotation.

Getting the parser working was an important project milestone because it transformed the original annotation files into a dataset that could be analyzed using standard Python data-science tools.
