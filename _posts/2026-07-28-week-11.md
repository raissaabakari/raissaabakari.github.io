This week involved a less glamorous but very real part of research: getting the software environment to cooperate.

I set up the project in VS Code and created a dedicated Python virtual environment. Installing the machine-learning dependencies initially produced errors related to Python package installation and Windows path lengths, particularly when installing PyTorch.

I eventually resolved this by moving the project into a shorter directory path and installing the required packages directly through the virtual environment.

The main libraries used in the experiment included:

- `pandas` and `NumPy`;
- `scikit-learn`;
- `sentence-transformers`;
- `Matplotlib`.

I also ran into a preprocessing bug where a filtering expression unexpectedly removed every row from the dataset. The issue turned out to be related to how a pipe character was being interpreted as a regular-expression operator. Fixing this restored the expected **1,796 experimental examples**.

Not the most exciting research week, but definitely one of the most realistic.
